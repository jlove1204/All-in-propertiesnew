OWNER DASHBOARD UPGRADE

Upload these 5 files to the ROOT of the GitHub repository:
- index.html
- admin.html
- api.js
- package.json
- vercel.json

This gives you an Owner Login and private dashboard to add/edit listings, publish/hide properties, block dates, and view reservations.

ONE-TIME SETUP AFTER UPLOAD:
1. Add OWNER_ADMIN_EMAIL in Vercel (Config, Production).
2. Create that exact email as a Supabase Authentication user with a strong password.
3. Do not share the password in chat.
